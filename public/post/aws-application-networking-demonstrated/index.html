A Minha Experiência Com O Exam Lab AWS Application Networking Demonstrated

  • 28/4/2026
  • 2-minute read

Fala, pessoal! Hoje eu queria compartilhar informações sobre a AWS Application Networking Demonstrated.

Para quem não conhece, o AWS Application Networking Demonstrated é um Exam Lab prático projetado pela própria AWS para ajudar a validar habilidades no domínio de Application Networking. Trata-se de uma avaliação cronometrada, super “mão na massa”, em que a gente trabalha dentro de um ambiente AWS ao vivo para diagnosticar problemas, implementar soluções e lidar com cenários comerciais reais que dependem dos serviços da nuvem.

Como funciona o Exam Lab?

Toda a avaliação é executada em um laboratório fornecido pela própria AWS. Após dar o start, você tem 90 minutos cravados para completar todos os desafios daquele ambiente. O laboratório informa as orientações dos procedimentos que você precisa atingir, mas não fornece dicas sobre como resolver.

Para conquistar a aprovação, o candidato precisa conhecer profundamente os serviços cobrados e realmente demonstrar competência em Application Networking.

Tópicos importantes de saber antes de começar:

  • Os desafios são aleatorizados e podem não estar em uma sequência óbvia ou lógica de cenários da vida real.
  • O Exam Lab não pode ser pausado e nem reiniciado. Se você fechar ou sair, precisará começar do zero novamente.
  • Caso você não seja aprovado de primeira no Exam Lab, será necessário aguardar 25 dias antes de tentar outra vez. Não vá fazer sem estar preparado(a)!

Objetivos do exame

Durante os desafios, é necessário verificar, solucionar problemas e implementar regras em vários componentes de rede das aplicações. Eis o escopo de serviços e objetivos:

  • Configurar o Amazon VPC Lattice
  • Corrigir o Application Load Balancer
  • Corrigir o dimensionamento do Elastic Container Service
  • Corrigir a integração do Amazon API Gateway
  • Configurar grupos de segurança
  • Criar alarmes do Amazon CloudWatch
  • Configurar o Amazon CloudFront

É uma experiência muito legal e até um pouco intensa, já que o tempo rolando em um ambiente live com problemas interconectados garante uma imersão total. Se você atua nessa frente técnica da AWS, recomendo muito o teste prático!

Bons estudos a todos! Keep learning. =)
